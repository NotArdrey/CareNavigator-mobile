# Visual Reference Guidance

Use `VISUAL_REFERENCE.png` as the visual quality benchmark for the new CareNavigator PH system.

## Reference strengths

### Mobile

- Clean white and cool-gray surfaces
- Compact branded app bars
- Clear search
- Limited quick actions
- Useful nearby-hospital summaries
- Practical operational status
- Clear bottom navigation
- Map-first discovery
- Structured hospital profile
- Step-based symptom assessment
- Preliminary guidance with clear disclaimer
- Patient dashboard focused on appointments, messages, records, and notifications

### Desktop

- One clear sidebar
- Compact top utility bar
- Scannable metrics
- Structured tables
- Operational hospital information
- Purposeful charts
- Clear status colors
- Professional density
- Strong alignment

## Important limits

The reference is not a pixel-perfect requirement.

Do not copy:

- Fictional names
- Fictional hospitals
- Fictional records
- Fictional appointment times
- Fictional metrics
- Fictional chart data
- Fictional avatars
- Fictional logos

Use production records from the connected data source. Automated tests may use isolated test records that are never rendered as production content.

The final product should be original and adapted to the actual CareNavigator PH workflows.
